## 2. Funcionalidades

A API é capaz de realizar as seguintes operações:

- ✅ Verificar o status da API.
- ✅ Listar todos os usuários cadastrados.
- ✅ Buscar um usuário específico por ID.
- ✅ Cadastrar novos usuários.
- ✅ Atualizar dados cadastrais de usuários existentes.
- ✅ Excluir usuários.
- ✅ Realizar login (validação de credenciais).
- ✅ Alterar a senha de um usuário (exigindo a senha atual).
